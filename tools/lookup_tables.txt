# The word lookup's two tables (core/local_dict.c rank_posting, docs/local-dictionaries.md), in one
# place for the reader and the converter: tools/gen_lookup_tables.py writes core/lookup_tables.inc
# from this file (local_dict.c includes it; the tools suite checks that it is current), and
# tools/convert_dictionary.py's table hints (--table-hints, and tools/prepare_plaintext.py for the
# bundled dictionary) mark each key's entry that a table names. After an edit:
#   python3 tools/gen_lookup_tables.py
# then prepare the bundled dictionary again and pin its new sha256 (docs/plaintext-dictionaries.json,
# key_filter): its table bits and the tables' id in its page 0 change with the tables.
#
# A line is one pair: the key as the index holds it (normalized: katakana as hiragana, full-width ASCII
# as ASCII), whitespace, then the value. A key is at most once in a table; '#' starts a comment.

[usual_spellings]
# The same form, for the frequency ranks alone: in a file with ranks, the key's entry with this
# spelling (or reading) ranks above the ranks' choice, as the more frequent entry would. Kana text
# whose word has no entry spelled in kana ranks the kanji spellings by how often each is written, and
# Jiten's ranks for kana text are its parser's lemma's: so the text's word lost to a homograph's
# spelling (いつか: ５日, による: 似寄る, なくなる: 亡くなる, audit-dict-freq N1; やめる: 辞める "resign"
# for 止める "stop", おじさん: 叔父さん "uncle" for 小父さん "mister", せい: 性 for 所為 "because of",
# audit-dict-freq-b; measured with tools/frequency_eval.py --frequency), and Jiten ranks 身体 しんたい
# just above the からだ visual novels use more. Unlike preferred_readings it only orders one key's
# entries: it never makes an entry count as written as the text, so the text's own entry (無くして,
# に依らず) still comes before its inflections' (無くす, に依る), and a file without ranks reads as
# before. Checked like preferred_readings (word_lookup's usual_spellings_win_in_the_bundle).
